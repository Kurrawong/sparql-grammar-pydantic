sparql-grammar

Typed Python objects for the SPARQL 1.2 grammar. Every example below is editable — change it and press the run button, or Shift+Enter.

Downloading the Python runtime (~10 MB, once). The run buttons appear when it is ready.

Build a query

The helpers assemble the productions for you, so a query is a nested literal rather than a tower of constructors.

Terms are explicit

No string is ever read as a term. var(), iri() and literal() say which one you mean, the way rdflib makes you choose between URIRef and Literal. The text alone cannot tell you — "<http://x>" is as plausibly a literal as an IRI, and a value read as a variable would widen a query rather than parameterise it. Python values that already carry a type pass straight through, and a stays the rdf:type keyword rather than a term.

Parse, then change it

Parsing gives back an ordinary object tree, so you can walk it, search it and edit it in place instead of rebuilding the query from scratch.
